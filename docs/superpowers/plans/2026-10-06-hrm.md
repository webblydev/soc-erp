# HRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the HRM module (docs/09 without payroll): employee master, HR lookups, documents with expiry, employment events, exit / rejoin, user linking, directory, profile, org chart, expiry list, and rewire the existing employee columns.

**Architecture:** A new `app/Modules/Hrm` module that copies the CRM module's structure: Auditable models, Action classes that authorize + validate + write in a transaction, class-based Livewire screens over BlatUI components, lookups edited on the shared Master Data screen. Other modules get `Employee::assignable()`, the `EmployeeDeactivated` event and an exit-check registry as hooks.

**Tech Stack:** Laravel 13 / PHP 8.4, Livewire 4 (class components, `Route::livewire`), BlatUI (`x-ui.*`), Tailwind v4, Pest 4 on in-memory SQLite.

**Spec:** `docs/superpowers/specs/2026-10-06-hrm-design.md` (decisions H1–H18). Read it with docs/09 before each task.

## Global Constraints

- Rules in `AGENTS.md` and `.ai/rules/modules.md`: module code in `app/Modules/Hrm/{Models,Livewire,Policies,Services,Actions,Events,Listeners,Jobs,Notifications,Concerns}`; migrations in `database/migrations/hrm/`; seeders in `database/seeders/Hrm/`; routes in `routes/modules/hrm.php` (required from `routes/web.php` the same way `crm.php` is); business logic only in Actions; every write Action uses `DB::transaction()`.
- UI only with BlatUI `x-ui.*` components, light mode only (no `dark:`), the strict mobile rules (top bar, bottom nav, list rows not tables, bottom sheets via `x-shell.sheet`, FAB, sticky save bar, 44 px targets, `wire:navigate` on every link, text ≥ 14 px on mobile).
- Route keys: `{employee:employee_code}`.
- Phones through `App\Support\Phone` (`normalise`, `rule()`).
- Commits: one commit per file-level change group, mid-length message, **no Co-Authored-By or AI footer** (user's global CLAUDE.md).
- Run `vendor/bin/pint --dirty --format agent` before each commit that touches PHP.
- Tests: `php artisan test --compact tests/Feature/Hrm/<File>.php`. Never run browser tests.
- No new composer / npm dependencies.

## Review Focus

1. **A user who is the employee themselves** opening their own profile without `view_full` must see their personal and salary fields but no edit buttons. Pinned in Task 4 (`EmployeePolicyTest`: "the linked user sees their own full and salary fields").
2. **Restricted input smuggled into Livewire** (`gross_salary` sent by a user without `update_salary`, `employee_status_id` set to an exit status) must be ignored / refused by the Action, not just hidden in the view. Pinned in Task 5 (`SaveEmployeeTest`: "salary input without update_salary is ignored", "an exit status cannot be set on the form").
3. **Linking a user already linked to another employee** (or vice versa, through the user form) must fail with a message, not a DB unique violation. Pinned in Task 7 (`LinkUserTest`: "a user linked elsewhere cannot be linked again").
4. **Exiting an employee whose linked user is the actor or the last super admin** must not leave the employee exited with an active user silently, nor crash. `ExitEmployee` deactivates through `SetUserActive`; its `ValidationException` must roll the exit back. Pinned in Task 6 (`ExitEmployeeTest`: "exiting your own employee record is refused and nothing changes").
5. **Manager or department-parent chosen from inside the employee's own reporting chain** must be refused (cycles) without an infinite loop on existing bad data. Pinned in Task 5 ("a manager cycle is refused") and Task 3 ("a department cannot be its own ancestor").

```php
public function withStatus(string $code): static
{
    $flags = [
        EmployeeStatus::ACTIVE => [true, false], EmployeeStatus::ON_LEAVE => [true, false], EmployeeStatus::SUSPENDED => [false, false],
        EmployeeStatus::RESIGNED => [false, true], EmployeeStatus::TERMINATED => [false, true], EmployeeStatus::RETIRED => [false, true],
    ][$code] ?? [true, false];

    return $this->state(fn (): array => ['employee_status_id' => EmployeeStatus::query()->where('code', $code)->value('id')
        ?? EmployeeStatus::factory()->create(['code' => $code, 'is_active_employment' => $flags[0], 'is_exit' => $flags[1]])->id]);
}

public function inDepartment(Department $department): static
{
    return $this->state(fn (): array => ['department_id' => $department->id]);
}

public function linkedTo(User $user): static
{
    return $this->afterCreating(fn (Employee $employee) => $user->forceFill(['employee_id' => $employee->id])->save());
}
```

```php
final class AssignableEmployee implements ValidationRule
{
    public function __construct(private int|string|null $current = null) {}

    public function validate(string $attribute, mixed $value, Closure $fail): void
    {
        if (! is_numeric($value)) {
            $fail(__('The selected :attribute is invalid.'));

            return;
        }

        if ($this->current !== null && (int) $value === (int) $this->current) {
            return;
        }

        if (! Employee::query()->assignable()->whereKey((int) $value)->exists()) {
            $fail(__('The selected :attribute is not an active employee.'));
        }
    }
}
```

```php
/**
 * A tree row cannot sit under itself or under one of its descendants. Walks up from the new
 * parent; the visited set stops a loop on bad existing data.
 *
 * @throws ValidationException
 */
private function ensureNotOwnAncestor(string $table, string $column, int|string $id, int $parentId): void
{
    $visited = [];

    for ($current = $parentId; $current !== null && ! in_array($current, $visited, true); $current = DB::table($table)->where('id', $current)->value($column)) {
        if ((int) $current === (int) $id) {
            throw ValidationException::withMessages([$column => __('A row cannot be placed under itself.')]);
        }

        $visited[] = $current;
    }
}
```

```php
/**
 * Employee access (docs/09 §2, spec H2). No row scope: everyone with view_basic sees the
 * directory. The linked user sees their own full and salary fields, read-only.
 */
class EmployeePolicy
{
    public function viewAny(User $user): bool { return $user->can('hrm.employees.view_basic'); }

    public function view(User $user, Employee $employee): bool { return $this->viewAny($user) || $this->isSelf($user, $employee); }

    public function viewFull(User $user, Employee $employee): bool { return $user->can('hrm.employees.view_full') || $this->isSelf($user, $employee); }

    public function viewSalary(User $user, Employee $employee): bool { return $user->can('hrm.employees.view_salary') || $this->isSelf($user, $employee); }

    public function create(User $user): bool { return $user->can('hrm.employees.create'); }

    public function update(User $user, Employee $employee): bool { return $user->can('hrm.employees.update'); }

    public function updateSalary(User $user, Employee $employee): bool { return $user->can('hrm.employees.update_salary'); }

    public function deactivate(User $user, Employee $employee): bool { return $user->can('hrm.employees.deactivate'); }

    public function viewDocuments(User $user, Employee $employee): bool { return $user->can('hrm.documents.view') && $this->viewFull($user, $employee) || $this->isSelf($user, $employee); }

    public function manageDocuments(User $user, Employee $employee): bool { return $user->can('hrm.documents.manage'); }

    public function manageHistory(User $user, Employee $employee): bool { return $user->can('hrm.history.manage'); }

    private function isSelf(User $user, Employee $employee): bool { return $user->employee_id !== null && $user->employee_id === $employee->id; }
}
```

```php
        'employee_status_id', 'branch_id', 'manager_id', 'phone', 'official_email', 'joining_date', 'confirmation_date', 'exit_date', 'exit_reason_id'];

        'present_address', 'permanent_address', 'emergency_contact_name', 'emergency_contact_relation', 'emergency_contact_phone', 'reference', 'tin', 'notes'];

    public const SALARY = ['gross_salary', 'bank_name', 'bank_account_no', 'mobile_wallet_no'];

    /** @return list<string> */
    public static function visibleTo(User $user, ?Employee $employee = null): array
    {

    }
```

```php
private function ensureNoManagerCycle(?Employee $employee, ?int $managerId): void
{
    if ($employee === null || $managerId === null) {
        return;
    }

    $visited = [];

    for ($current = $managerId; $current !== null && ! in_array($current, $visited, true); $current = Employee::withTrashed()->whereKey($current)->value('manager_id')) {
        if ($current === $employee->id) {
            throw ValidationException::withMessages(['manager_id' => __('An employee cannot report to themselves or to someone who reports to them.')]);
        }

        $visited[] = $current;
    }
}
```

```php
final class ExitChecks
{
    /** @var list<class-string<EmployeeExitCheck>> */
    private array $checks = [];

    /** @param class-string<EmployeeExitCheck> $class */
    public function register(string $class): void
    {
        if (! in_array($class, $this->checks, true)) {
            $this->checks[] = $class;
        }
    }

    /** @return list<ExitCheckItem> */
    public function run(Employee $employee): array
    {
        return array_merge(...array_map(fn (string $class): array => app($class)->check($employee), $this->checks)) ?: [];
    }

    public function blocks(Employee $employee): bool
    {
        return collect($this->run($employee))->contains(fn (ExitCheckItem $item): bool => $item->blocking);
    }
}
```
